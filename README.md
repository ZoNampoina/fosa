# FOSA

FOSA est un intercom/talkback vocal expérimental pour musiciens.

## v0.1.0
- Android, iPhone et PC via navigateur HTTPS
- Supabase Realtime : présence + signalisation
- WebRTC P2P : transport de la voix
- Push-to-Talk
- cible Tous / rôle / participant
- écoute individuelle ON/OFF
- noise suppression, echo cancellation, auto gain
- diagnostics RTT / jitter / pertes
- aucun enregistrement audio

Le TURN n'est pas encore configuré ; les premiers tests doivent privilégier des appareils sur le même réseau Wi‑Fi.
